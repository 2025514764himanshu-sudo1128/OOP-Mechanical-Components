# Experiment 02: OOP for Mechanical Component Modelling

---

## Aim
To model specialized mechanical components using Classes, Inheritance, and Encapsulation in Python.

---

## Concepts Covered
- Class and Object creation
- Inheritance (base class → derived class)
- Encapsulation (private attributes + getter methods)
- Volume and Mass calculations using OOP

---

## Formulas Used

| Formula | Description |
|---|---|
| V = π × r² × L | Volume of cylindrical shaft |
| m = ρ × V | Mass of shaft |

## Installation Steps

### Step 1: Install Python
```
1. Go to https://www.python.org/downloads/
2. Download Python 3.11 or above
3. During installation CHECK "Add Python to PATH"
4. Verify: python --version
```

### Step 2: Install Required Libraries
```bash
pip install math
```
Note: `math` is built-in — no installation needed!

## How to Run
